# Utf8Json native AOT smoke test

A small app that uses Utf8Json the way a native AOT app should:
- formatters pre-generated by `Utf8Json.UniversalCodeGenerator`
- composed with `BuiltinResolver` and `EnumResolver`
- no `StandardResolver`

CI (the `aot-smoke` job in `.github/workflows/dotnet.yml`) publishes it with `PublishAot=true`, treating trim/AOT warnings as errors, and then runs the native executable. Any regression in the AOT-safe paths therefore fails the build: a new warning, or a failing check.

This project is not part of `Utf8Json.sln`.

## Run locally

```
dotnet publish tests/Utf8Json.AotSmokeTest -c Release -r <rid> -o aot-out
./aot-out/Utf8Json.AotSmokeTest
```

Use `win-x64`, `linux-x64` or `osx-arm64` as the RID. Native AOT needs the platform toolchain: on Windows, the Visual Studio C++ build tools (with `vswhere.exe` on PATH); on Linux, `clang` and `zlib1g-dev`.

## Regenerate the formatters

After changing `Models/`, regenerate the checked-in output. CI fails if it is stale.

```
dotnet run --project src/Utf8Json.UniversalCodeGenerator -c Release -f net10.0 -- -d tests/Utf8Json.AotSmokeTest/Models -o tests/Utf8Json.AotSmokeTest/Generated/Utf8JsonGenerated.cs -n AotSmoke
```
